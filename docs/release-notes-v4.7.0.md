# EasyBow v4.7.0

发布日期：2026-10-26

本版本完善需求 Markdown 到浏览器测试的执行闭环，并增强重复执行效率与复杂页面定位。

## 新功能

- 测试面板支持导入 Markdown 文件，按段处理完整需求，生成多个独立用例。
- 用例关联需求与验收点编号，报告显示通过、失败、未执行和未覆盖状态。
- 结构化断言由测试引擎逐条执行；模型不能通过重复断言、遗漏预期或修改通过标准来影响结论。
- 测试会话默认隔离，支持显式复用登录态、数据驱动、失败后清理及失败用例完整重跑。
- 已验证的参数化流程可复用；目标重新解析，定位失效时停用旧计划并交回 AI。
- 新增局部元素观察、快照时效校验、跨域 iframe 作用域断言和嵌套 frame 定位增强。
- 新增当前模型的固定语义场景测评入口，展示逐项结果、耗时分位数与 Token 用量。

## 修复

- 求值异常、无效选择器、缺失响应体或不可达框架不会因断言取反而误判通过。
- 接口断言按当前步骤请求检查点、HTTP 方法和请求完成状态过滤，排除历史请求。
- 导航动作正确展开 `{{base_url}}`；断言阶段暂停恢复不重复业务操作。
- 强制重置测试会兑现序列等待，避免重置后仍无法开始新测试。
- AX 状态按浏览器 properties 读取；跨域 frame 中的同源嵌套字段保留定位链。
- 图片解码使用标准空白宿主页，关闭后台节流并清理解码超时计时器。
- 修复全量自测遗留定时任务弹窗的问题；自测超时不再返回成功。
- 自动化验收固定关闭后台节流，避免共享桌面切换焦点导致 CDP 输入长时间等待。

## 使用

打开工具栏“测试”→ 导入需求 MD → 生成并审核用例 → 选择测试环境 → 运行并查看覆盖报告。

缺少明确业务预期的用例会标记为“待确认”，补充结构化断言后才能运行。旧的自然语言预期也需要补充为 `[文字]`、`[URL]`、`[选择器 X]` 或 `[接口 X]` 等格式。

模型固定场景测评需要 6 次模型调用；这是语义契约筛查，不能替代真实站点及视觉操作能力测评。复杂业务组件和各服务商的实际效果仍需使用目标环境验证。
